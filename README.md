# CareRide Connect — ดราฟ 1
เว็บไซต์ HTML/CSS/JavaScript พร้อมภาพทั้ง 10 ภาพ ใช้ได้บน GitHub Pages โดยไม่ต้องติดตั้งหรือ build

## วิธีอัปโหลด GitHub
1. แตกไฟล์ ZIP นี้
2. สร้าง repository ใหม่ใน GitHub หรือเปิด repository ที่ต้องการ
3. เลือก Add file > Upload files และอัปโหลด index.html, styles.css, app.js และโฟลเดอร์ assets ให้ index.html อยู่ระดับแรกของ repository
4. กด Commit changes
5. ไป Settings > Pages > Deploy from a branch > main > /(root) > Save
6. รอให้ GitHub Pages แสดงลิงก์เว็บไซต์

เปิด index.html ดูในเครื่องได้ ฟอนต์ Google ต้องเชื่อมอินเทอร์เน็ต หากโหลดไม่ได้จะใช้ฟอนต์สำรอง

## ไฟล์
- index.html — เนื้อหาและโครงสร้างเว็บ
- styles.css — สี รูปแบบ และการแสดงผลบนมือถือ
- app.js — ข้อมูลรถ ราคา การเลือกประเภท และฟอร์มสรุป
- assets/ — ภาพจากผู้ใช้ แปลงเป็น WebP เพื่อลดขนาด

## ขอบเขตดราฟ
- ราคาตัวอย่างนำมาจากภาพอ้างอิง ไม่ใช่ราคาเสนอขายที่ยืนยันแล้ว
- ฟอร์มประเมินใช้กฎตัวอย่าง ไม่ใช่การประเมินทางการแพทย์
- ข้อมูลฟอร์มอยู่เฉพาะหน้าเว็บ ไม่บันทึกและไม่ส่งออกไปยังเซิร์ฟเวอร์
- ปุ่มคัดลอกทำงานได้บน HTTPS เช่น GitHub Pages
- ยังไม่เชื่อม LINE โทรศัพท์ ระบบจอง หรือระบบหลังบ้าน ต้องใส่ช่องทางจริงก่อนเปิดรับลูกค้า
- ข้อความเกี่ยวกับบริการและอุปกรณ์ต้องตรวจสอบกับผู้ให้บริการก่อนใช้งานจริง

เปลี่ยนราคา/ข้อมูลรถในตัวแปร vehicles ของ app.js เปลี่ยนข้อความหลักและช่องทางติดต่อใน index.html
